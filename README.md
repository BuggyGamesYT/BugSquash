# Bug Squash

A fast, glitchy arcade game for Android by **Buggy Games YT**.

RGB-glitching bugs crawl in from the edges of the screen. Tap them before they escape!

- 🐛 **Normal bugs**: 1 point. Let one escape and you lose a life.
- ⭐ **Golden bugs**: 5 points, and a chance to win back a life.
- 🦠 **Red viruses**: never tap them, or you lose a life.
- 🔥 **Combos**: chain squashes for up to a x5 multiplier.
- 📈 Speed ramps up the longer you survive. Your high score is saved.
- 🏆 **Online Top 10**: get a top score and put your 3-character name on the leaderboard, shared with the [web version](https://buggygamesyt.github.io/bugsquash/).

## Download

Grab [`release/BugSquash.apk`](release/BugSquash.apk) or the latest [release](../../releases), then open it on your phone and allow "install unknown apps". The APK is self-signed, so Play Protect may show a warning.

- Android 7.0+ (API 24), targets Android 17 (API 37)
- Package: `com.buggygames.bugsquash`

## Build

Plain Java + Android SDK build tools (aapt2, d8, zipalign, apksigner), no Gradle. See `build.sh`.

YouTube: https://www.youtube.com/@BuggyGamesYT
